## 🚀 The Mission

**Personal Finance ETL** is a comprehensive, automated data pipeline ecosystem designed for precise personal net worth tracking and advanced financial analytics.

> **⚠️ IMPORTANT:** This codebase is a **highly customized Medallion Architecture Template** tailored to the author's specific broker and bank data formats. It provides the complete underlying architecture (orchestration, state management, analytics, and UI) required to build a personal household data warehouse, but requires developers to write their own custom extraction logic for their specific banks.

The application leverages a modern Medallion Lakehouse architecture (powered by DuckDB and Polars) to extract, clean, and consolidate disparate financial records into a single source of truth. Moving beyond simple spreadsheet tracking, it offers advanced capabilities including automated tax harvesting analysis, strict cashflow monitoring, and Numba JIT-compiled Monte Carlo simulations to project FIRE (Financial Independence, Retire Early) milestones.
